version: v3.3
date: "2026-03-28"
title: HTML-first wireframing
description: |
  Wireframing moves to HTML-first. Mockups are built as lo-fi HTML you view in the browser, not Markdown documents.
changes:
  - "HTML wireframe is the default and primary format. The mockup grows section by section in a single HTML file. You preview it in the browser and give feedback live"
  - "Iterative build in batches: pages with 4+ sections are split into logical narrative groups, and you review each batch before the next one starts"
  - "Six design lenses: User Question, Narrative Arc, Content Priority, Persuasion, Task, Awareness"
  - "New knowledge base wireframe-craft.md: rules for building lo-fi HTML, CSS architecture, section patterns, anti-patterns"
  - Markdown wireframe is still available as an alternative deliverable, not the only format
---
