title: Mapping an existing site into lo-fi wireframes
description: |
  New workflow: map an existing site into lo-fi wireframes. Available only in the IDE versions (Claude Code, Codex, Antigravity).
changes:
  - Standalone entry point. No prior brief or strategy required. A site URL or a file (HTML, sitemap, screenshots) is enough
  - Automatic setup for the content-fetch tool. The agent checks availability, installs missing components, and runs them in the background. If your environment is bare, it walks you through the install step by step
  - "Page-template recognition with confidence levels: Confident / Uncertain / Skipped. The agent shows what it considered and why it excluded a candidate, and you approve the list before further work"
  - The wireframe reflects the current state without judging the UX. Same quality and format as a new-site design, with the original copy from your site
