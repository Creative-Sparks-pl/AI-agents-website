title: Personal link and automatic updates
description: |
  You install the assistant from your own personal link, and new versions install themselves at the start of a session.
changes:
  - "<strong>Install from your personal link.</strong> You paste one sentence with your link into your coding assistant (Claude Code, Codex or Cursor), and it downloads the package and installs the assistant following INSTALL.md. Your license is already in the package, so there is nothing for you to copy."
  - "<strong>Updates by themselves.</strong> At the start of a session the assistant checks whether a new version is waiting, installs it and asks you to start a new session, and it asks first about every file you changed. You can turn automatic updates off with one request to the assistant, and then it only tells you that a new version is waiting."
  - "<strong>What the check sends.</strong> Only your customer ID, the package name and the version number. Nothing about your projects, files, clients or conversations."
  - "<strong>The assistant keeps working.</strong> You can use it with no time limit, and you get updates for a year from purchase, which you can extend. It works as usual without internet, and it stops only after a refunded order or when the link has been blocked, for example after it was shared with other people."
  - "<strong>A bigger package arrives as an update.</strong> When you buy a bigger package, you get it at the next start, with your changes and settings kept."
  - "<strong>New name ux-design, as a skill only.</strong> The assistant now installs as ux-design, and a copy under the old name is moved to the new one, with your changes and a backup. The package now holds only the skill version, without the agent version started with /expert."
